# 제출 — 시연 영상 대본과 심사위원 실행 안내

- 앱 주소: https://approval-planner-arlb.axhub.app
- 영상 요건: 5분 이내 권장, 1080p 권장, **음성 해설 필수**, **실제 작동과 모의 처리를 말로 구분**, 빨리 감은 구간은 화면에 "빨리 감기" 표시.
- 녹화 전 준비: 브라우저 1440px 이상, 확대 100%, 브라우저 언어 한국어(날짜 칸이 연·월·일로 보이게). 위쪽 메뉴 "시연"에서 장면을 고르고 "초기화하고 시작"을 누르면 그 장면만 남고 메인으로 간다.
- 진행 방식: 메인 위쪽 시연 막대의 **▶ 진행**을 누르면 하루씩 넘어가고, 부서 회신·리뷰·반품·판매 같은 바깥 사건은 도착일에 저절로 들어온다. 누군가 결정해야 하면 막대가 멈추고 "OO의 승인이 필요해요"와 **OO로 바꾸기** 단추가 뜬다. 결정은 시연자가 화면에서 직접 누른다.
- 표기: **[누름]** = 화면에서 누를 것, **[말]** = 해설, **(모의)** = 모의 처리라고 말할 곳

"다음 일까지"는 조용한 날을 건너뜁니다.
   - 장면 1 정상: 7월 3일 물류 회신 뒤 7월 16일(마지막 승인일)에 멈추고, Masil 대표가 승인하면 7월 20일에 1차 집행이 됩니다.
   - 장면 2 조건 변경: 그룹 CEO로 보면 재고 부족으로 일반 승인이 막히고 분할 승인만 됩니다. 뒤로 가면 반품 기준 초과로 2차가 자동 보류됩니다.
   - 장면 3 정보 부족·승인 없음: 7월 14일(기본 거부 실행일)에 기본 거부와 조건변경 통보 초안이 생깁니다.

6. 메뉴: 메인(시연 막대·할 일·일정 띠), 회신 입력, 기록(처리 기록·AI 호출·가정 목록), 정책(기준값·출처·변경 이력), 등록(기안·계약), 시연.
