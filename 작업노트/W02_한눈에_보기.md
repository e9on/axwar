# W02 한눈에 보기

- 기준: 2026-11-10 · 상세 내용은 설계 문서와 구현 계획에 있음
- 이 문서는 변수 이름 없이 **목표 · 방법 · 방향 · 결과**로만 정리한 요약본

---

## 한 줄 요약

> 회사가 **깜빡해서 손해 보는 계약을 자동으로 연장하지 않도록**, 기한 전에 먼저 움직이고 결재권자에게 근거를 들고 가는 운영 시스템.

---

## 1. 전체

| | 내용 |
|---|---|
| **목표** | 인플루언서 전속계약(연 28억)과 캠페인 확대 기안을 **정해진 결재 권한 안에서** 처리한다. 보고서가 아니라 실제로 승인 요청·할 일 생성·상태 변경이 일어나는 시스템을 만든다. |
| **방법** | 원본 데이터로 돈의 흐름을 계산 → 규칙이 결재권자와 기한을 판정 → AI가 글을 읽고 써서 돕기 → 결과를 저장하고 다음 판단에 다시 사용 → 화면에서 사람이 결정 |
| **방향** | 숫자·기한·권한은 **규칙**이 정한다(틀리면 안 되니까). 사람 말을 읽고 글을 쓰는 일만 **AI**가 돕는다. 결재가 없으면 **기본은 거부**. |
| **결과** | 시연 장면 3개(정상 / 조건 변경 / 정보 부족·무승인)가 화면에서 처음부터 끝까지 돌아간다. |

---

## 2. 왜 필요한가 (원본에서 확인한 사실)

- 혜인 전속계약: 연 28억, **7/17까지 말이 없으면 1년 자동 연장**, 연장 뒤 해지하면 위약금
- 혜인은 광고비를 **가장 많이 받는데(40.6%, 1위)** 실제 수익성은 **10명 중 9위(마이너스)** → 돈이 거꾸로 배분되고 있음
- 같은 날(7/17) 혜인 캠페인 확대 기안 3건도 마감 → 기한 지나면 자동 확정
- 7/21~8/22 회사 잔고가 **30억 아래**로 내려감 → 이 기간에 돈이 나가는 약속은 **그룹 CEO**가 결재해야 함
- 재무팀 공식 전망은 이 하락을 못 잡았음(7/21 한꺼번에 나가는 발주 대금, 큰 거래처의 결제 지연이 빠져 있음)

---

## 3. 판단 원칙 6가지

1. **결재권자의 승인이 핵심**이다. 시스템은 권한을 넘는 결정을 스스로 확정하지 않는다.
2. **승인이 없으면 기본은 거부**다. 이익보다 손실을 먼저 막는다.
3. 거부하더라도 **해지가 아니라 "조건을 바꾸자"는 통보**를 보낸다. 결재권자가 못 봤을 수도 있고, 바로 해지하면 다시 협상하기 어렵다.
4. 결정이 **핵심 지표와 반대**면(성과가 나쁜데 늘리거나, 좋은데 줄이면) 결재권자를 한 명 더 붙인다.
5. 성과가 좋은 건이라도 승인 없이 기한이 오면 거부한다. 대신 **기한 5일 전에 한 단계 위로 미리 경고**한다.
6. 조건이 바뀌어 **결재권자가 바뀌면 이유를 보여주고**, 원래 보던 사람에게도 알린다.

## 4. 영역별 정리

### 4-1. 돈의 흐름 계산

| | 내용 |
|---|---|
| **목표** | 판단에 쓸 숫자를 원본 데이터에서 직접, 정해진 계산식대로 뽑는다. |
| **방법** | 날짜별 잔고 계산(언제 30억 아래로 가는지), 인플루언서별 실제 수익성 순위, 반품 사유별 비율, 남는 재고와 입고 날짜 |
| **방향** | 원본은 읽기만 한다. 같은 돈을 두 번 빼지 않는다(쿠폰·환불·발주 대금). 표본 데이터는 비율·순위로만 말한다. |
| **결과** | ✅ 완료(작업 3개 모두 검토 통과). 미리 계산해 둔 값과 모두 일치: 잔고 하락 7/21~8/22, 최저 약 19.2억 / 혜인 수익성 9위 / 혜인 단순변심 반품 3.6%(다른 인플루언서 1.8%) |

### 4-2. 판단 규칙

| | 내용 |
|---|---|
| **목표** | 각 건마다 **누가 결재하는지, 언제까지인지, 얼마나 나눠서 할지**를 정한다. |
| **방법** | 결재권자 판정(금액·잔고 하락 기간·지표 방향), 결재권자가 바뀔 때 이유 기록, 기한 5일 전 경고와 기한 당일 기본 거부, 물류 한도·재고·입고일로 1차·2차 수량 나누기, 1차 뒤 리뷰·반품을 보고 2차를 멈출지 판정 |
| **방향** | 사람마다 결과가 달라지지 않게 **계산식처럼** 정한다. 날짜 경계(7/17, 7/21, 8/22, 8/23)는 테스트로 고정한다. |
| **결과** | ⏳ 다음 차례. 예: 혜인 기초 캠페인 확대는 잔고 하락 기간에 돈이 나가서 CEO·이사회 결재 → 물류가 "1,800건만 가능"이라 하면 1차 1,800건(7/27), 2차 2,200건(8/24, 반품을 28일 지켜본 뒤) → 2차는 하락 기간 밖이라 결재권자가 Masil 대표로 바뀜 |

### 4-3. AI

| | 내용 |
|---|---|
| **목표** | 규칙으로 처리할 수 없는 **사람의 말**을 읽고, 결재권자가 읽을 **글**을 쓴다. |
| **방법** | 읽기: 고객 리뷰(색이 영상과 다른지, 화났는지), 부서 회신("1,800건까지 가능", "확인해 보고 말씀드릴게요"). 쓰기: 결재권자 요약, 반대 근거, 조건변경 통보문 초안 |
| **방향** | AI가 쓴 내용에는 항상 "AI" 표시와 확신도를 붙인다. 확신이 낮거나 답이 이상하면 **사람에게 넘긴다**. 테스트에서는 실제 AI를 부르지 않는다(비용 0). |
| **결과** | ⏳ 예정. 모델 8개를 시험 중이며, 정확도가 충분한 모델 중 **가장 싼 것**을 고른다. |

### 4-4. 시스템 상태와 시연

| | 내용 |
|---|---|
| **목표** | 결정·회신·리뷰가 쌓이고, **바뀐 상태가 다음 판단에 쓰이게** 한다. |
| **방법** | 모든 건·결재·할 일·회신·AI 호출을 저장. 날짜를 앞으로 옮기면 기한을 점검해 경고·거부를 자동 실행. 같은 버튼을 두 번 눌러도 한 번만 반영. |
| **방향** | 결재권자가 아닌 사람은 결재할 수 없다. 날짜는 뒤로 돌릴 수 없다(초기화로만). |
| **결과** | ⏳ 예정. 시연 3장면이 화면 없이도 자동 테스트로 끝까지 통과하는 것이 목표. |

### 4-5. 화면

| | 내용 |
|---|---|
| **목표** | 결재권자가 **가장 먼저 봐야 할 것(결재권자, 기한, 버튼)**을 가장 먼저 보게 한다. |
| **방법** | 메인: 사람별 할 일 + 날짜 타임라인. 건 상세: 왼쪽 근거, 오른쪽 결정. 회신 입력, 2차 관찰, 시연 조작판, 처리 기록. |
| **방향** | 디자인 규칙 10개 적용(카드만 나열 금지, 흔한 AI풍 금지, 반응형). 근거마다 "원본 / 계산 / 가정 / 회신 / AI" 색 배지. |
| **결과** | ⏳ 예정. **시작 전에 디자인 방향 2~3개를 보여드리고 골라 주시면** 진행. 완성 후 데스크톱·태블릿·휴대폰 화면을 직접 찍어 확인. |

### 4-6. 배포

| | 내용 |
|---|---|
| **목표** | 대회 심사자가 주소 하나로 들어와 시연을 볼 수 있게 한다. |
| **방법** | 화면과 서버를 하나로 묶어 axhub(lounge)에 올린다. 자동 검사로 매번 확인. |
| **방향** | API 키는 프로젝트 밖과 배포 설정에만 둔다. |
| **결과** | ⏳ 예정. **앱 이름을 정해 주시면** 배포. |

## 5. 시연 장면 3개

| 장면 | 목표 | 흐름 | 보여줄 결과 |
|---|---|---|---|
| **1. 정상** | 문제없는 건은 빠르게 처리되는 모습 | 수익성 1위 인플루언서의 확대 기안 → Masil 대표 결재 → 물류 "전량 가능" | 물류 출고·고객센터 대비 할 일이 자동 생성 |
| **2. 조건 변경** | 조건이 바뀌면 결재권자와 계획이 바뀌는 모습 | 혜인 기초 캠페인 확대 → CEO·이사회 결재 → 물류 "1,800건만" → 1차·2차 분할 → 2차는 Masil 대표로 이동 → 1차 뒤 "색이 영상과 달라요" 리뷰 → 28일 뒤 반품 집계 | 리뷰는 콘텐츠 수정 요청과 사람 확인으로, 반품이 평소보다 확실히 많으면 2차 자동 보류 |
| **3. 정보 부족·무승인** | 결재가 없으면 손실을 막는 모습 | 혜인 전속계약 → 7/12 이사회에 미리 경고 → 7/17까지 결재 없음 | 자동 연장 대신 조건변경 통보 초안, 기안 3건 보류, 상대가 "검토 후 회신"이면 사람 확인으로 |

## 6. 돈 (AI 사용 예산)

| | 내용 |
|---|---|
| **목표** | 충전한 5달러 안에서 시험·개발·시연을 모두 끝낸다. |
| **방법** | 지금까지 약 3달러 사용(모델 시험). 남은 약 2달러를 시연 1달러, 추가 시험 0.5달러, 연결 확인 0.1달러, 예비 0.4달러로 나눔. |
| **방향** | 자동 테스트는 가짜 AI로 돌려 비용 0. 앱 안에 한도(전체 1달러, 하루 0.3달러)를 두고 넘으면 AI를 멈춤. 무료인 Gemini를 먼저 고려. |
| **결과** | 시험에서 가장 비싼 모델(Opus)이 비용의 3분의 2 → 다음 시험부터는 제외 |

## 8. 직접 정한 가정 (원본에 없어서 정한 것)

- 조건변경 통보를 보내면 자동 연장이 막힌다고 본다
- 통보는 계약 담당이 보낸다
- 반품되면 원가는 돌려받지 못한다고 본다
- 혜인 기초 캠페인 요청 수량은 4,000건으로 둔다
- 2차 자동 보류는 반품으로만 판단: 1차 반품률이 혜인 평소 반품률보다 우연으로 볼 수 없을 만큼 높을 때(통계 기준 95%). 리뷰는 경고와 사람 확인용
- 2차는 1차 뒤 28일을 지켜본 뒤에 연다(반품의 90%가 28일 안에 확정)
- 주문 1건은 상품 1개로 본다 — 원본에 수량이 없고 금액으로도 역산이 안 됨. 다른 가정을 넣어도 혜인은 최하위권이라 결론은 같음
- 기한 5일 전에 미리 경고한다
- AI 확신도 0.7 미만이면 사람에게 넘긴다
- 리뷰는 원본에 없어서 시연용 가상 리뷰를 쓴다
