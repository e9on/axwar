# 시연 직접 해 보기 — 장면별 누르는 순서

- 주소: **http://127.0.0.1:8803/** (항상 메인 주소로 들어가 위쪽 메뉴로 이동. 주소창에 하위 주소를 직접 치거나 건 화면에서 새로고침하면 "Not Found")
- 장면 시작: 위쪽 메뉴 **시연** → 장면 고르기 → **초기화하고 시작** → 메인으로 이동
- 공통 진행법: 메인 위 막대의 **▶ 진행** → 멈추면 **OO로 바꾸기** → 할 일 **열기** → 처리 → 위쪽 **메인** → 다시 **▶ 진행**
- 마지막 승인일에 결정을 덜 하고 진행을 누르면 "오늘이 마지막 승인일이에요" 창이 떠요. 시연 중이면 **취소**.
- 2차 집행일은 처음부터 1차 + 반품 관찰 28일 + 승인 여유로 잡혀요(장면 2 계열은 8/28).
- SCM 안전재고 회신 전에는 승인·분할 승인이 막혀요(거절은 가능).
- 결재는 승인할 수 있게 된 날부터 할 일과 일정 띠(승인 기간 막대)에 보이고, 진행은 **마지막 승인일**에 멈춰요. 그 전에 할 일에서 먼저 해도 돼요.
