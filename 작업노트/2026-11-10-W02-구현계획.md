# W02 인플루언서 계약·캠페인 집행 운영 시스템 구현 계획

> **에이전트 작업자용:** 필수 하위 스킬은 superpowers:subagent-driven-development(권장) 또는 superpowers:executing-plans. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 승인 권한 경계 안에서 혜인 전속계약과 캠페인 확대 기안을 처리하고, 바뀐 상태가 다음 판단에 쓰이는 웹 시스템을 만든다.

**구조:** 원본 CSV를 읽기만 하는 계산(`calc`) → 순수 함수 규칙(`rules`) → AI 해석·글쓰기(`ai`) → SQLite 상태와 이벤트 엔진·API(`core`) → React 화면(`frontend`). 숫자·기한·권한은 규칙이, 문장 해석과 글쓰기는 AI가 맡는다.

**스택:** Python 3.11, FastAPI, uv, pytest, sqlite3(표준 라이브러리) / TypeScript, React, Vite, Vitest, Playwright / Docker, axhub(lounge).

**설계:** `작업노트/2026-11-10-W02-설계.md` (실행자는 설계와 이 계획을 함께 읽는다)
